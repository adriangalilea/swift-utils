- [ ] **mac-app-release.yml: the app half of the pipeline.** `lib-release.yml` ships and covers libraries; a mac APP adds build → sign → notarize → staple → dmg on top, then forks by distribution channel: `sparkle` (appcast via `generate_appcast`, for the GUI apps) or `cask` (bump a Homebrew cask in adriangalilea/homebrew-*, for CLI-shaped apps like awake). The words gate is a `notes/<version>.md` file committed in the consuming repo: CI asserts it exists for the version being built and refuses otherwise, git-cliff only DRAFTS it locally (`make notes`), never writes prose users read. That one file is the GitHub Release body, the appcast item's release notes (`generate_appcast` picks up a same-basename `.md` and Sparkle 2.9 renders markdown natively on macOS 12+), and the source for the in-app Changelog surface below. Version source INVERTS from the library pipeline: an app bundle has a native version field, so the manifest is truth (`CFBundleShortVersionString`, templated from the Makefile's `VERSION` for hand-assembled bundles like awake, `MARKETING_VERSION` in project.yml for the XcodeGen apps) and CI derives the tag from it, rather than reading the tag. Sparkle's build number stays monotonic off the live feed, never typed. Everything runs on `macos-26`, so git-cliff comes from `brew install git-cliff`, not the Docker action. Secrets a consumer must set: Developer ID p12 + password, App Store Connect API key, Sparkle EdDSA key (sparkle channel) or a tap PAT (cask channel). Prior art to lift wholesale: `untitled/tools/release/lib.ts`.

  **The notes SHAPE travels with this.** An app's notes are rendered by the studio, which DESIGNS releases rather than dumping markdown, so the body MUST be `### heading` lines with `- ` items: prose parses to zero groups and renders as a dated heading with nothing underneath (awake shipped three releases that way). The group NAMES are a soft convention on top: `Added|Fixed|Changed|Performance|Polish` earn a designed glyph and colour, anything else falls back to `·` and still renders, so the library's emoji groups would not break, they would just look plain. Consequence for any app adopting this: ship a `cliff.toml` so `make notes` DRAFTS into that shape (the seed is what the human edits, so a wrong seed is the actual bug), and gate `make release` on it locally, before anything is signed or published, rather than discovering it when the surface renders blank. awake carries both today (`apps/awake/.github/cliff.toml` + the grep in its `release` target); this pipeline should own them so the next app inherits instead of copying.
